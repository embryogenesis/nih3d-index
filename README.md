# An index of the NIH 3D Print Exchange

**16,294 live entries**, found by asking for every id from 1 to
24,000. Generated 2026-11-24.

`3d.nih.gov` publishes thousands of models and **offers no way to list them**.
`/api/entries`, `?limit=`, `?page=&size=`, `/api/search?q=` and `/sitemap.xml`
all return 404; only `/api/entries/3DPX-NNNNNN` answers. This is what you get
by asking for every id, so that the catalogue can be searched, filtered and
diffed by anyone who needs to.

## What this is, and is not

This is **factual metadata** — ids, titles, categories, licences, file
extensions. **No model files are copied here.** Every entry links back to its
page on `3d.nih.gov`, and each carries its own licence, recorded below and
unaltered.

The index itself is offered under [CC0](LICENSE): it is a list of facts about
a public catalogue, and nobody should have to ask before using it.

## Method

Ids 1 to 24,000, six concurrent requests, 120 ms between batches,
exponential backoff on 429 and 5xx, resumable. 24,000 ids asked,
16,294 answered; the rest are 404.

**The id range is sparse.** `000100`, `019000` and `025000` are all 404 while
ids either side exist, so a gap means only "not this one" and never "the end".
The upper bound was found by probing: `023xxx` answers, `024000` does not.

Generated by `tools/probe-nih3d-sweep.ts` in the embryogenesis atlas. Re-running
it regenerates every file here from the same index, sorted identically, so a
later sweep produces a diff that is exactly what the host gained or lost.

## Accuracy

Taken from the host's own API on the date above and not corrected. Where a
title has odd spacing or a licence is recorded oddly, that is what the API
returned.
